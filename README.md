# Week 2 Assignments

Java solutions for five string-processing exercises.

## Questions

- `q1` - ATM PIN length validator
- `q2` - Word reversal encoder
- `q3` - Product inventory CSV parser
- `q4` - Library ISBN normalizer and validator
- `q5` - Stop-word-filtered word frequency report

## Run a Solution

Each folder contains `Main.java` and the compiled `Main.class` file.

From the repository root, run a solution with:

```powershell
java -cp q1 Main
java -cp q2 Main
java -cp q3 Main
java -cp q4 Main
java -cp q5 Main
```

Enter the requested input when prompted.

## Recompile

To recompile one solution:

```powershell
javac q1\Main.java
```

Replace `q1` with `q2`, `q3`, `q4`, or `q5` as needed.
